Cómo combinarlas para una página con animaciones

  1. Antes de diseñarspec-kit o superpowers para escribir el plan, y context7 para que Claude consulte documentación actual.
  2. Dirección visualui-ux-pro-max propone el sistema; taste-skill e impeccable vetan los clichés de IA; frontend-design obliga a decidir antes de codear.
  3. Movimientogenjutsu y gsap-skills para un solo momento de animación bien orquestado, con magic-mcp si necesitas componentes animados.
  4. Construcciónagent-skills de Vercel para Next.js y el MCP de shadcn para componentes accesibles.
  5. Comprobaciónplaywright-mcp y chrome-devtools-mcp para verla funcionar; Lighthouse y a11y-mcp para rendimiento y accesibilidad.
